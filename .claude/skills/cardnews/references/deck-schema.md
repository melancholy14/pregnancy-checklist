# deck JSON 스펙

`tools/cardnews/decks/<slug>.json`의 구조. `render.mjs`가 이 필드들을 읽어 카드 HTML로 조립한다.

## 최상위 구조

```json
{
  "slug": "gov-benefits-2026",
  "cards": [ ... ],
  "caption": "...",
  "hashtags": ["#임신", "..."]
}
```

- `slug`: 출력 폴더명(`out/<slug>/`). 글 슬러그보다 짧게 줄여도 됨.
- `cards`: 카드 배열 (6~8개 권장, 인스타 캐러셀 최대 10개).
- `caption`·`hashtags`: 피드 게시글용. `INDEX.txt`에 복붙용으로 출력됨.

## 카드 타입별 필드

### cover (표지, 1장)
```json
{
  "type": "cover",
  "kicker": "2026 임신·출산 정부 혜택",
  "title": "나라에서 주는 돈,\n몰라서 *그냥 놓치면\n너무 아까워요*",
  "sub": "국민행복카드부터 부모급여까지\n초산맘이 시점별로 정리했어요",
  "swipe": "넘겨서 확인 →"
}
```
- `kicker`: 라벤더 pill. 글 카테고리/시리즈명.
- `title`: 큰 훅. **`*..*`로 감싼 부분만 핑크 형광펜.** 형광펜은 표지 title에서만 작동한다(render.mjs가 cover에만 적용).
- `sub`: 회색 서브카피. "개발자 초산맘이 직접…" 정체성 훅을 여기.
- `swipe`: 생략 시 "넘겨서 확인 →".

### body (본문, 4~6장)
```json
{
  "type": "body",
  "num": "01.",
  "title": "임신하면\n진료비 100만원",
  "paras": ["문단 1", "문단 2"],
  "callout": { "tone": "tip", "label": "💡 꿀팁", "text": "..." },
  "stat": [ { "big": "100만원", "cap": "단태아" }, { "big": "200만원", "cap": "쌍둥이" } ]
}
```
- `num`: 넘버링(선택). 본문 카드 순서대로 `01.` `02.`… "큰 그림" 도입 카드는 num 없이 둔다.
- `title`: 카드 헤드라인. 글 H2/FAQ 질문을 짧게 압축.
- `paras`: 문단 배열. **1~2개까지.** 길면 카드가 답답하다. 문장은 짧게.
- `callout`: 강조 박스(선택). `tone`은 아래 파스텔 역할표를 반드시 따른다.
- `stat`: 숫자 박스 배열(선택). 2개가 나란히 제일 예쁨. `big`=큰 수치, `cap`=아래 설명.
- **callout과 stat을 한 카드에 둘 다 넣으면 하단이 빡빡**하니 되도록 하나만. 둘 다 필요하면 카드를 나눠라.
- 페이지 번호(`N / total`)는 export.mjs가 본문 카드에 **자동 주입**한다. 직접 넣지 마라.

### cta (마무리, 1장)
```json
{
  "type": "cta",
  "title": "카드사별 사은품 비교와\n주차별 신청 타임라인은?",
  "link": "프로필 링크에서 전체 글 확인 👆",
  "handle": "@pregnancy.checklist"
}
```
- `title`: 남은 가치를 궁금하게. 단 **글에 실제로 있는 내용**만. 랜딩(홈)에 없는 개인화 기능처럼 오해 주는 표현 금지.
- `link`: 프로필 링크 유도 문구.
- `handle`: 항상 `@pregnancy.checklist`.

## 텍스트 마크업

- `\n` → 줄바꿈. 제목은 의미 단위로 끊어라(한글 `word-break: keep-all` 위에서 어절이 어색하게 안 잘리게).
- `*강조*` → 핑크 형광펜. **cover title 전용.** body/cta에서는 무시된다.
- 특수기호는 그대로 렌더되지만, 인스타 **바이오**엔 `✓`·따옴표가 거부되니 그건 카드가 아니라 바이오 세팅 때 주의(카드 이미지엔 무관).

## 파스텔 역할 (섞지 말 것)

사이트 DESIGN.md의 5파스텔 역할을 그대로 강제한다. 콜아웃 `tone` 선택 기준:

| tone | 색 | 역할 | 언제 |
|---|---|---|---|
| `tip` | 옐로 | 정보·팁 | "이건 알아두면 좋아요" 류 |
| `data` | 피치 | 수치·주의 | 금액·기한·놓치기 쉬운 것 |
| `ok` | 민트 | 긍정·확인 | "된다/받는다/중복 가능" 류 |

라벨 이모지는 역할에 맞춰: tip=💡, data=📌, ok=🔔/✔️.

## 캡션·해시태그

### caption 포맷 (한 문자열, `\n`으로 줄바꿈)
1. **훅 1~2문장** — 글 authorNote나 공감 포인트. 이모지 1개 정도.
2. **✔️ 요약 3~5줄** — 카드 핵심을 불릿으로. 수치 그대로.
3. **CTA 1줄** — "전체는 프로필 링크에서 확인하세요 👆" + `@pregnancy.checklist`.
4. **면책 1줄** — 주제 맞춤(정책/금융이면 정책 면책, 의학이면 의학 면책). `※`로 시작.

### hashtags (배열, 15~20개)
- **대형 태그**(도달): `#임신` `#출산준비` `#예비맘` `#임산부` `#맘스타그램`
- **니치 태그**(정확도): 글 주제 키워드. 예) `#국민행복카드` `#부모급여` `#첫만남이용권`
- 대형만 쓰면 묻히고, 니치만 쓰면 도달이 좁다. **섞어라.**

## 완성 예시

레퍼런스로 `tools/cardnews/decks/gov-benefits-2026.json`(정부혜택 7장)을 볼 것. 표지 형광펜, 스탯 2종, tip/data/ok 콜아웃, 캡션·해시태그가 모두 들어간 정본이다.
