## 측정 근거 — W25에서 본 신호

런칭 전략의 출발점은 W25 주간 리포트(2026-06-15~21)에서 처음 잡힌 실데이터:

- page_view 123, 활성유저 6 (직전 W24는 0/0 — 휴면 상태였음)
- 유입 채널: **Unassigned 8 / Direct 3 / Referral 3** ← 측정 실패 신호
- 랜딩: `/` 6세션 + 아티클·체크리스트 분산 1씩

**핵심 교훈: 인스타는 GA4에서 Unassigned/Direct로 새는 최악의 채널이다.**
인앱 웹뷰(특히 iOS)가 referrer를 통째로 날린다. UTM을 안 박으면 인스타 성과를 0% 측정하게 된다.

## 1. Attribution 세팅 (런칭 D-1주, 코드 최소)

런칭 첫 글부터 데이터가 깨끗하게 찍히도록 **글 올리기 전에** 링크 규칙을 박는다.

### 1.1 UTM 체계

| 위치 | utm_source | utm_medium | utm_campaign |
|---|---|---|---|
| 바이오 링크 | `instagram` | `bio` | (고정 또는 시즌) |
| 스토리 / 릴스 링크 스티커 | `instagram` | `story` | `<글-슬러그>` |
| 피드 게시물(바이오 유도) | `instagram` | `post` | `<글-슬러그>` |

- `utm_campaign`에 글 슬러그를 박으면 → GA4에서 "어느 콘텐츠가 유입을 끌었나"가 그대로 집계됨.
- 이게 인스타 운영의 핵심 피드백 루프. 효자 글 식별 → 비슷한 글 더 생산.

### 1.2 gtag lazyOnload 검증 (필수)

- 현재 `gtag`가 `lazyOnload`로 로드됨 (커밋 befff36, FCP 개선용).
- **인스타 유입은 "탭 → 3초 보고 뒤로가기"가 흔해서, gtag가 늦게 뜨면 세션이 통째로 측정 누락될 위험.**
- 런칭 전 실제 인스타 앱에서 링크 눌러 → GA4 Realtime에 잡히는지 확인.
- 누락되면 gtag 로드 전략 조정(`afterInteractive` 등) 검토.

### 1.3 GA4 internal traffic filter
- pre-launch 동안 비활성(dogfooding이 트래픽 전부라). **인스타 런칭 = 외부 유입 시작 시점에 Active 전환.**
- 동시에 본인 IP/디바이스를 internal로 등록해 운영자 방문이 데이터를 오염시키지 않게.

## 2. 콘텐츠 ↔ 사이트 연결 전략 (런칭 후 운영)

### 2.1 계정 컨셉 — **미정 (런칭 시 결정)**
후보: ① 릴스 중심 ② 카드뉴스 중심 ③ 정보성 캡션 중심.
- 임신·출산·육아 정보 도메인이라 **카드뉴스 + 정보성 캡션**이 사이트 글과 연결이 자연스러움.
- 릴스는 도달은 높지만 사이트 클릭 전환은 약함 → 인지도용 보조.

### 2.2 글 → 인스타 변환 루프
- 사이트 발행 글 1개 → 인스타 카드뉴스 1세트로 요약 → 캡션 끝에 "전문은 프로필 링크".
- 바이오 링크는 단일 URL이므로, 글이 늘면 **링크 허브(예: 사이트 내 `/articles` 또는 링크인바이오 페이지) + 스토리 하이라이트**로 분기.

### 2.3 추적 지표 (런칭 후 주간 리포트에서 봐야 할 것)
- 인스타 utm_campaign별 세션·전환 (어느 글이 효자인가)
- **홈(`/`) vs 아티클 랜딩 비율** — 아티클 랜딩이 늘면 = 콘텐츠가 유입을 직접 끄는 단계 진입
- Unassigned 비율 추이 — UTM 세팅이 제대로 먹는지 역으로 검증

## 3. 단계 1 액션 (2026-07-01 ~ 휴가 진입, AdSense 재신청 SoT)

목적은 트래픽이 아니라 **Google 크롤러에 "외부에서 이 사이트가 참조된다" 신호 보내기**.
재신청 D-2주 시점에 시그널 작동 시작 → 인덱싱 우선순위 상승 → 색인 페이지 ≥ 15 도달.

### 3.1 7월 초 최소 작업 (출산·휴가 직전이라 운영 강도 최소화)

- [ ] 인스타 계정 생성 + 바이오에 사이트 URL 박음 (`?utm_source=instagram&utm_medium=bio`)
- [ ] 게시 2~3건 — 발행 글 17편 중 효자 후보 (예: 산후조리원·정부지원·체크리스트)
- [ ] 본인 SNS / 맘카페 1~2곳에 자연스러운 사이트 링크 (스팸성 X)
- [ ] gtag 인스타 웹뷰 측정 누락 검증 (Realtime) — 시그널 측정 작동 확인용

### 3.2 단계 1에서 안 하는 것 (산후 복귀 후 단계 2로)

- 정기 게시 캘린더 (모멘텀이 필요한 영역 → 휴면 손해)
- UTM 체계 풀세팅 (3슬롯 모두) — 단계 1은 bio + 게시 2종 정도면 충분
- internal traffic filter Active 전환 — 외부 트래픽 본격 시작 시점 기준
- 바이오 링크 허브 분기 구조 (글 자산 더 쌓인 후)
- 카드뉴스 변환 루프 (콘텐츠 운영 부담 큼)

### 3.3 단계 1 종료 신호

- AdSense 재신청 결과 통보 직후 (승인/거절 무관)
- 휴가 진입 직전 (7월 중순)

이 시점에 인스타 계정은 **휴면 진입** — 산후 복귀 후 단계 2 진입까지 잠재 상태로 둠.

## 4. 단계 2 액션 (2026-11 ~, 본격 마케팅 드라이브)

### 4.1 Attribution 풀세팅 (런칭 D-1주)

UTM 체계 3슬롯 풀가동:

| 위치 | utm_source | utm_medium | utm_campaign |
| --- | --- | --- | --- |
| 바이오 링크 | `instagram` | `bio` | (고정 또는 시즌) |
| 스토리 / 릴스 링크 스티커 | `instagram` | `story` | `<글-슬러그>` |
| 피드 게시물(바이오 유도) | `instagram` | `post` | `<글-슬러그>` |

- `utm_campaign`에 글 슬러그 → GA4에서 "어느 콘텐츠가 유입을 끌었나" 집계
- 인스타 운영의 핵심 피드백 루프. 효자 글 식별 → 비슷한 글 생산

### 4.2 본격 운영 체크리스트

- [ ] 인스타 계정 컨셉 확정 (카드뉴스 / 릴스 / 캡션 비중)
- [ ] UTM 체계 3슬롯 확정 + 링크 생성 규칙 문서화
- [ ] gtag 인스타 웹뷰 측정 누락 재검증 (몇 달 묵힌 세팅 신선도 확인)
- [ ] GA4 internal traffic filter Active 전환 + 본인 디바이스 등록
- [ ] 바이오 링크 허브 전략 (단일 URL → 분기 구조)
- [ ] 첫 4주 콘텐츠 캘린더 (기존 글 → 카드뉴스 변환분)
- [ ] 주간 리포트에 인스타 campaign별·랜딩 비율 추적 슬롯 확인 (Wave 2 채널·랜딩 섹션)
